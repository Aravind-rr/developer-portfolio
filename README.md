# Aravind Raghuram T A — Developer Portfolio

A responsive, motion-aware developer portfolio for Aravind Raghuram T A. It showcases verified public projects spanning AI/ML, full-stack development, cybersecurity, IoT, logistics, and intelligent document processing.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run check
npm run build
```

The project is configured for Vercel as a Vite single-page application.

## Stack

- React + TypeScript
- Vite
- Lucide icons
- Custom responsive CSS
